# 文档中心

这里是本模板的唯一文档入口。新人不要从任意专题文档开始，也不要把多份文档的示例拼在一起使用。

## 新人阅读顺序

1. [开发指南](./DEVELOPMENT_GUIDE.md)：从复制模板到提交组件的完整流程。
2. [UI 与样式约束](./ui-design-spec.md)：开发页面和组件时必须遵守的视觉边界。
3. 按需查阅其他专题，不要求通读。

## 文档优先级

发生冲突时按以下顺序处理：

1. 实际代码和 `project.config.js`；
2. 本目录中的文档；
3. README、历史讨论和 AI 生成内容。

发现文档与代码不一致时，应在同一个提交中修正文档。不要新增内容相近的文档；优先修改现有专题。

## 最小交付标准

每次功能提交至少满足：

- `pnpm run type-check` 通过；
- `pnpm build` 通过，并出现 `✓ UMD validated`；
- 组件已在开发预览中验证亮色、暗色和窄屏；
- 修改配置、对外接口或开发流程时，同步更新对应文档；
- 未引入第二份 Vue，也未在组件内直接使用 `fetch` 或 `axios`。
